# ReWear AI 디자인 가이드

이 문서는 현재 구현된 ReWear AI의 화면, 화면 전환, 데이터 요청과 상태 표시를 정리합니다. 앱에는 A 옷장 목록, B 옷 상세, C 코디 추천 바텀 시트가 있습니다.

## 1. 화면 구성과 흐름

| 화면 | 이름 | 파일 | 진입 방식 | 데이터 |
|---|---|---|---|---|
| A | 내 옷장 | `lib/screens/a_list_screen.dart` | 앱 시작 화면 | 로컬 json-server `GET /items` |
| B | 옷 상세 | `lib/screens/b_detail_screen.dart` | A에서 옷 카드를 눌러 화면 쌓기 | 메모 탭에서 `GET /notes?itemId=...` |
| C | 코디 추천 | `lib/screens/c_result_sheet.dart` | B에서 `결과 보기`를 눌러 바텀 시트 열기 | 코드에 미리 정의한 코디 예시 |

```text
A 옷장 ── 카드 누르기(push) ──▶ B 옷 상세 ── 정보 | 메모 탭 전환 ──▶
                                      └─ 결과 보기 ── 바텀 시트 열기 ──▶ C 코디 추천
```

- A에서 창 너비가 600dp 미만이면 목록, 600dp 이상이면 격자로 옷을 표시합니다.
- B의 정보와 메모는 탭으로 전환합니다.
- C는 별도 페이지가 아닌 바텀 시트이며 닫기 버튼이나 아래로 끌어 닫을 수 있습니다.

## 2. 화면별 요소와 동작

### A — 옷장

| 요소 | 위젯 및 표시 내용 | 동작 및 원칙 |
|---|---|---|
| A-1 | AppBar, ReWear AI 제목 | 화면 제목을 일관되게 표시합니다. P04 일관성과 표준 |
| A-2 | ListView와 옷 카드 | 옷의 이미지, 이름, 설명, 분류, 색상과 태그를 표시합니다. 카드를 누르면 B로 이동합니다. P08 미학적이고 간결한 디자인 |
| A-3 | 넓은 화면의 GridView | 창 너비 600dp 이상에서 격자로 표시합니다. |
| A-4 | LoadingView | `GET /items`를 기다리는 동안 옷장 로딩 안내를 표시합니다. P01 시스템 상태의 가시성 |
| A-5 | ErrorView와 다시 시도 버튼 | 요청 실패 메시지와 재요청 동작을 표시합니다. P09 오류 인식·진단·복구 지원 |
| A-6 | EmptyView | 서버 응답의 원본 옷 목록이 비어 있을 때 빈 옷장 안내를 표시합니다. P01 시스템 상태의 가시성 |

옷 목록은 로컬 json-server의 `GET /items` 응답으로 구성하며 현재 데이터에는 옷 12개가 있습니다. 카드에는 JSON의 `image` URL을 사용하는 옷 사진을 표시하며, 사진 로드에 실패하면 이미지 아이콘을 대신 표시합니다. 카드 위에서 분류와 색상을 선택할 수 있습니다. 분류 선택지는 `전체`, `상의`, `하의`, `신발`이며 색상 선택지는 `전체 색상`, `흰색`, `파란색`, `검은색`, `노란색`, `갈색`, `분홍색`, `회색`입니다. 두 조건은 동시에 적용됩니다. 원본 목록이 비어 있으면 A-6 빈 옷장 안내를, 원본 목록은 있지만 조건에 맞는 옷이 없으면 별도의 안내와 `필터 초기화` 버튼을 표시합니다. 초기화 버튼은 두 필터를 모두 전체로 되돌립니다.

### B — 옷 상세

| 요소 | 위젯 및 표시 내용 | 동작 및 원칙 |
|---|---|---|
| B-1 | AppBar와 뒤로 가기 | 선택한 옷 이름을 제목으로 표시하고 이전 화면으로 돌아갑니다. P03 사용자 통제와 자유 |
| B-2 | `정보`·`메모` TabBar | 두 탭을 전환합니다. |
| B-3 | JSON 이미지 URL을 사용하는 옷 이미지, 이름, 설명 | A에서 선택한 옷의 상세 정보를 표시합니다. 이미지 로드에 실패하면 이미지 아이콘을 표시합니다. P02 시스템과 실세계의 일치 |
| B-4 | 태그 Chip | 옷에 연결된 태그를 표시합니다. P08 미학적이고 간결한 디자인 |
| B-5 | `저장 (예시)` 버튼 | 누르면 저장하지 않는다는 SnackBar를 표시합니다. 실제 저장이나 영구 보관은 하지 않습니다. |
| B-6 | `결과 보기` 버튼 | C 코디 추천 바텀 시트를 엽니다. P07 사용의 유연성과 효율성 |
| B-7 | 메모 목록 및 상태 표시 | `GET /notes?itemId=...`로 해당 옷의 메모를 가져옵니다. 로딩, 요청 실패와 다시 시도, 메모가 없는 상태를 표시합니다. P01 시스템 상태의 가시성, P09 오류 복구 지원 |

## 3. C — 코디 추천 바텀 시트

| 요소 | 위젯 및 표시 내용 | 동작 및 원칙 |
|---|---|---|
| C-1 | `showModalBottomSheet` | B에서 `결과 보기`를 누르면 열립니다. 닫기 버튼 또는 아래로 끌어 닫을 수 있습니다. P03 사용자 통제와 자유 |
| C-2 | 선택한 옷 안내 | 바텀 시트에서 기준으로 삼은 옷 이름을 보여 줍니다. P01 시스템 상태의 가시성 |
| C-3 | 스타일 ChoiceChip과 코디 정보 카드 | 스타일을 선택하면 해당 코디의 이름, 스타일, 옷 조합, 추천 상황과 설명을 함께 바꿉니다. P06 기억보다 재인 |
| C-4 | 예시 안내 문구 | 미리 준비된 예시이며 실제 AI 분석 결과가 아님을 안내합니다. P10 도움말과 문서 |

미리 정의된 코디는 세 가지입니다. 이름과 색상은 옷장 데이터와 일치하며, 각 코디는 스타일, 아이템 조합, 추천 상황과 설명을 함께 표시합니다.

| 스타일 | 코디 이름 | 옷 조합 | 설명 |
|---|---|---|---|
| `캐주얼` | 캐주얼 데일리룩 | 노란색 반팔 티셔츠 · 회색 트레이닝 팬츠 · 검은색 스니커즈 | 학교 수업·등하교, 편한 일상 외출. 산뜻한 티셔츠와 활동성 있는 아이템 조합입니다. |
| `러블리` | 러블리 스커트룩 | 분홍색 니트 · 화이트 미니 스커트 · 화이트 베이직 스니커즈 | 주말 약속·카페 나들이. 분홍색 니트와 밝은 스커트로 부드러운 분위기를 냅니다. |
| `미니멀` | 미니멀 레이어드룩 | 흰색 니트 · 회색 트레이닝 팬츠 · 갈색 롱코트 · 검은색 스니커즈 | 일상 외출·도서관. 차분한 색을 겹쳐 입어 깔끔하고 편안한 분위기를 냅니다. |

코디와 설명은 모두 고정된 예시입니다. AI 모델, 외부 API 또는 실제 추천 알고리즘을 사용하지 않습니다.

## 4. 화면 상태와 임시 UI 상태

| 상태 또는 입력 | 변경 위치 | 화면에 반영되는 내용 |
|---|---|---|
| A의 로딩·오류·원본 빈 목록 | `GET /items` 응답 | A-4 로딩 안내, A-5 오류 및 다시 시도, A-6 빈 옷장 안내 |
| A의 분류·색상 선택 | A 상단 ChoiceChip | A-2 옷 카드 목록 또는 조건에 맞는 옷이 없다는 안내와 `필터 초기화` 버튼 |
| B의 메모 로딩·오류·빈 목록 | `GET /notes?itemId=...` 응답 | B-7 메모 탭의 상태 또는 메모 목록 |
| C의 선택 코디 | C 스타일 ChoiceChip | C-3 선택된 코디의 이름, 스타일, 옷 조합, 추천 상황과 설명 |

화면 내 선택 상태는 Flutter의 `StatefulWidget`과 `setState`로만 처리합니다. `저장 (예시)` 버튼은 안내용 SnackBar만 표시합니다.
